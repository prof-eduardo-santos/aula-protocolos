Protocolos de Rede

Qual é a definição de protocolo de rede?

Um protocolo de rede é um conjunto de regras que define como os dispositivos trocam informações entre si.

Camada de Aplicação

Reúne os protocolos utilizados pelos programas e usuários.

HTTP

Permite o acesso às páginas da Web.

DNS

Traduz nomes de sites em endereços IP.

Camada de Transporte

Realiza a comunicação entre os programas dos dispositivos.

TCP

Entrega os dados de forma confiável e ordenada.

UDP

Prioriza a rapidez da comunicação.

Camada de Rede

Encaminha os pacotes entre redes diferentes.

IP

Identifica os dispositivos e encaminha os pacotes.

DHCP

Fornece automaticamente as configurações da rede.

Camada de Enlace

Transmite dados entre dispositivos ligados à mesma rede.

Ethernet

Permite a comunicação em redes locais com fio.

Wi-Fi

Permite a comunicação em redes locais sem fio.
